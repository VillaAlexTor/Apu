# Provenance — login Atlas topográfico andino

- **Generator:** OpenAI built-in ImageGen
- **Use case:** `ui-mockup`
- **Purpose:** north-star composition for the shared APU web login
- **Selected direction:** Atlas topográfico andino

## Generation brief

Create a high-fidelity landscape desktop login for APU integrated into
Bolivian topographic cartography. Use contour lines, survey-map paper, forest
green, mineral red and surveying yellow. The form must remain contemporary,
legible and accessible. It is one shared login for guardians, tenant
administrators and internal operators; the backend resolves permissions and
destination only after authentication. Do not present a role selector. Avoid
literal folklore, surveillance imagery, fabricated metrics, customer claims,
watermarks and generic floating-card composition.

Required interface content: APU, email, password, show-password control,
primary sign-in action, password recovery and a short explanation that access
is routed safely according to permissions.

The resulting composition is stored in `login-atlas.webp` and is the approved
visual reference for implementation.
